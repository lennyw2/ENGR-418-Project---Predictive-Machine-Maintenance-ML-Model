# ENGR-418-Project---Predictive-Machine-Maintenance-ML-Model
SUMMARY: This repository is to document the ENGR 418 course project. A dataset was taken from Kaggle that simulated various measurements from different industrial equipment with the purpose of predicting if the equipment is faulty or not. Various logistic regression and random forest models were created to analyze the effectiveness of different techniques.

Project Objective: As was summarized above, this repository documents the ENGR 418 course project which requires that students complete a self defined machine learning project on a real world problem. Predictive Machine Maintenance is the issue that was selected for this project. A simulated dataset was selected from Kaggle. The dataset includes vibration, temperature, humidity, equipment type, and location of equipment that is either classified as faulty or not faulty. The task is then to produce a machine learning model that can accurately predict if the equipment is faulty or not based on the aforementioned features. To start, the data was analyzed to look over outliers, imbalances, or other statistical features that may require adjustments to train an effective model. A logistic regression model was used as a baseline with all features. The model was then tuned using various different techniques to maximize the effectiveness of the model. Lastly, a few random forest models were created to show the limitations of a logistic regression model. 

Usage instructions: The "Industrial Monitoring Dataset" from Kaggle (link pasted below and file included in repository) must be downloaded as a .csv file first before using the python code. The code was created on google colab. The first block of code is used to upload the dataset. Run the first block, select the 'Choose Files' button right below the code block, and navigate to the downloaded 'equipment_anomaly_data.csv' file. Each code block can then be run in sequential order. 
Kaggle Dataset: https://www.kaggle.com/datasets/dnkumars/industrial-equipment-monitoring-dataset

Key Findings: 
  1. DATA ANALYSIS: The initial data analysis showed that the data was imbalanced. 90% of the dataset was classified as not faulty (0) and only 10% classified as faulty (1). The location was only used for information to show which places had more faulty equipment, but it was not deemed useful for training the model. No outliers were found, and the data had a good balance of data based on equipment type. The pearson correlation heatmap and the feature vs faulty plot both showed a strong correlation of vibration with the classification and moderate correlation of temperature and pressure with the classification. The humidity and equipment type showed negligible correlation to the classification.
  2. LOGISTIC REGRESSION MODEL: A baseline logistic regression model was then created using all the features. This model proved to have relatively poor performance. Scaling the data did not improve the performance. Using a sequential feature selector and exhaustive feature selector eliminated the humidity and equipment type which improved the performance. Seperating the equipment types into different models did not improve the performance. The weighting was then changed to a custom one to improve the recall (very important in an industrial setting to reduce missed faults). Finally, lowering the threshold improved the recall even further. At this point, it was assumed that enough was done to bring the model close to performing at its best; a different model type was needed to improved performance further.
  3. RANDOM FOREST MODEL: The logistic regression model was believed to have been limited by its inability to pick up on nonlinear relationships in the dataset. A random forest model was created as an example of a model that can pick up on nonlinear relationships better. A random forest model uses multiple decision trees to make predictions based on the features of the dataset. A decision is then made based on the output of all the decision trees. This results in a model that can pick up on more complicated data relationships that a logistic regression model. This is shown in the base model performance, and it is also shown in the second random forest which had better performance using all the features because it could pick up on subtle relationships between the data. The threshold was then lowered for the third and final random forest model which improved the recall to 0.95 (highest of all models) and the balanced accuracy to 0.966 (highest of all models.
  4. ACCURACY VS BALANCED ACCURACY: An interesting observation on the final results is that the accuracy of every model is >0.8 which appears quite good. This shows the limitations of using accuracy as a performance metric when dealing with imbalanced data or problems where certain classifications are weighted more heavily then others because it will treat the classification of all data the same. The balanced accuracy will do a much better job of showing the true performance of the model because it balances the accuracy across both classifications.

CONCLUSION: This project showed several effective techniques for making a machine learning model more accurate including data analysis, feature selection, weight adjustment, and threshold changing. The logistic regression model was used to try to predict faulty equipment. The effectiveness of the model was drastically improved using the aforementioned techniques until the limit of the model was reached. The random forest model was then shown to be much more effective at reading the nonlinear relationships in the data.
